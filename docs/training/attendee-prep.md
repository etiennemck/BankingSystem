# Attendee Preparation: Spec-Driven Development Demo

- **Starter repo:** Get the workshop copy with the synthetic PRD, exercise brief,
  and existing backend. Start from a fresh branch or worktree.
- **Product context:** Review the PRD and brief. The exercise is a standalone
  evaluator, not live transfer enforcement.
- **Tools:** Have Git, a terminal, and an AI coding agent ready. For Droid, make
  sure Spec Kit is initialized and the `/speckit-*` commands are available.
- **Build:** Install Java 21. The Maven wrapper handles Maven; first build may
  need network access. Baseline check: `cd backend; .\mvnw.cmd -B "-DskipTests" test-compile`.
- **Not needed:** Docker, Jira/Confluence, production credentials, or customer
  data.
